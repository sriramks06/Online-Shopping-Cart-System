Description

A Java console-based Shopping Cart Application that simulates a simple e-commerce experience.
Users can add and remove products, view their cart, and see total cost updates dynamically. This project showcases CRUD operations using Java Collections.

🚀 Features

Add or remove products dynamically

View all items and total cost

Handle invalid input gracefully

Menu-driven interface for smooth interaction

🛠️ Tech Stack

Language: Java SE

Concepts Used: OOP, ArrayList, Loops, Conditionals, User Input

📂 Project Structure
ShoppingCart/
 ├── Item.java
 ├── Cart.java
 └── Main.java

▶️ How to Run
javac *.java
java Main

🎯 Learning Outcomes

Using Collections Framework effectively

Implementing CRUD functionality in Java

Structuring modular and reusable classes
